    Tile Info - Stores info about how to draw a tile

    Constructor

    new TileInfo(pos, size, textureInfo, padding, bleed, columns)engineDraw.js:165

    Create a tile info object

    pos Vector2 optional, default vec2()

    Top left corner of tile in pixels

    size Vector2 optional

    Size of tile in pixels

    textureInfo TextureInfo optional

    Texture info to use

    padding number optional

    How many pixels padding around all sides of each tile (increases grid size, does not affect tile size)

    bleed number optional

    How many pixels smaller to shrink UVS of tiles (does not affect grid size, only UVs)

    columns number optional, default 0

    How many frames per row for frame(), 0 to keep frames on a single row
