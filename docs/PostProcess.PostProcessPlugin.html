    PostProcessPlugin

    Post Process Plugin - Applies a full screen shader to the rendered output

    • Create it after any plugin that draws, since plugins render in the order they are made and this one shades what is on the canvas when its turn comes
    • It runs after gameRenderPost, so a HUD drawn there with WebGL is shaded (and bloomed) too; draw the HUD with useWebGL=false (the main canvas) or from a plugin created after this one

    Constructor

    new PostProcessPlugin(shaderCode, includeMainCanvas, feedbackTexture)postProcess.js:31

    Create global post processing shader

    shaderCode string optional

    Shadertoy style mainImage code, a pass-through when left out

    includeMainCanvas boolean optional, default false

    combine mainCanvas onto glCanvas

    feedbackTexture boolean optional, default false

    also pass the shader's own output from the previous frame as iChannel1, for trails and echoes; iChannel0 is still the frame just drawn

    // create the post process plugin object
new PostProcessPlugin(shaderCode);
