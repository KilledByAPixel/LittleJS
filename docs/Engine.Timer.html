    Timer

    Timer object tracks how long has passed since it was set

    Constructor

    new Timer(timeLeft, useRealTime)engineUtilities.js:25

    Create a timer object set time passed in

    timeLeft number optional

    How much time left before the timer is elapsed in seconds (undefined = unset)

    useRealTime boolean optional, default false

    Should the timer keep running even when the game is paused? (useful for UI)

    let a = new Timer;    // creates a timer that is not set
a.set(3);             // sets the timer to 3 seconds

let b = new Timer(1); // creates a timer with 1 second left
b.unset();            // unset the timer
