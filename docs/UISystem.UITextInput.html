    UITextInput - An editable text input field

    • A simple text entry field that supports basic editing
    • Suitable for short text input like names or numbers
    • Reads a physical keyboard: no on-screen keyboard opens on touch devices, and IME composition and paste do not type, use an HTML input element for those
