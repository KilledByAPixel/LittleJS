    ParticleEmitter

    Particle Emitter - Spawns particles with the given settings

    Extends EngineObject

    Constructor

    new ParticleEmitter(pos, angle, emitSize, emitTime, emitRate, emitConeAngle, tileInfo, colorStartA, colorStartB, colorEndA, colorEndB, particleTime, sizeStart, sizeEnd, speed, angleSpeed, damping, angleDamping, gravityScale, particleConeAngle, fadeRate, randomness, collideLevel, additive, randomColorLinear, renderOrder, localSpace)engineParticles.js:49

    Create a particle system with the given settings

    pos Vector2

    World space position of the emitter

    angle number optional

    Angle to emit the particles

    emitSize number|Vector2 optional, default 0

    World space size of the emitter (float for circle diameter, vec2 for rect)

    emitTime number optional, default 0

    How long to stay alive (0 is forever)

    emitRate number optional, default 100

    How many particles per second to spawn, does not emit if 0

    emitConeAngle number optional, default PI

    Half angle of the cone around the emitter's angle that particles move along, PI is every direction

    tileInfo TileInfo optional

    Tile info to render particles (undefined is untextured)

    colorStartA Color optional, default WHITE

    Color at start of life 1, randomized between start colors

    colorStartB Color optional, default WHITE

    Color at start of life 2, randomized between start colors

    colorEndA Color optional, default CLEAR_WHITE

    Color at end of life 1, randomized between end colors

    colorEndB Color optional, default CLEAR_WHITE

    Color at end of life 2, randomized between end colors

    particleTime number optional, default 0.5

    How long particles live

    sizeStart number optional, default 0.1

    How big are particles at start

    sizeEnd number optional, default 1

    How big are particles at end

    speed number optional, default 0.1

    How fast are particles when spawned, in world units per frame (at 60fps, so multiply units/sec by 1/60)

    angleSpeed number optional, default 0.05

    How fast are particles rotating, in radians per frame (at 60fps)

    damping number optional, default 1

    How much to dampen particle speed, per-frame velocity multiplier (1 = no damping, .9 = lose 10% speed each frame)

    angleDamping number optional, default 1

    How much to dampen particle angular speed, per-frame multiplier (1 = no damping)

    gravityScale number optional, default 0

    How much gravity affects particles

    particleConeAngle number optional

    Half angle each side of the emitter's angle for a particle's start angle, PI is any angle

    fadeRate number optional, default 0.1

    Fraction of life spent fading: half at fade-in (start), half at fade-out (end). e.g. .2 = 10% fade-in, 80% full opacity, 10% fade-out

    randomness number optional, default 0.2

    Apply extra randomness percent

    collideLevel boolean optional, default false

    Do particles collide with the level's tiles, world space emitters only

    additive boolean optional, default false

    Should particles use additive blend

    randomColorLinear boolean optional, default true

    Should color be randomized linearly or across each component

    renderOrder number optional

    Render order for particles (additive is above other stuff by default)

    localSpace boolean optional, default false

    Should it be in local space of emitter (world space is default)

    // create a particle emitter
let pos = vec2(2,3);
let particleEmitter = new ParticleEmitter
(
    pos, 0, 1, 0, 500, PI,      // pos, angle, emitSize, emitTime, emitRate, emitConeAngle
    tile(0, 16),                // tileInfo
    rgb(1,1,1,1), rgb(0,0,0,1), // colorStartA, colorStartB
    rgb(1,1,1,0), rgb(0,0,0,0), // colorEndA, colorEndB
    1, .2, .2, .1, .05,  // particleTime, sizeStart, sizeEnd, speed, angleSpeed
    .99, 1, 1, PI, .05,  // damping, angleDamping, gravityScale, particleConeAngle, fadeRate
    .5, true             // randomness, collideLevel
);
