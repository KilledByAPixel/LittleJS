    Extends UIObject

    Constructor

    new UIVideo(pos, size, src, autoplay, loop, volume)uiSystem.js:1747

    Create a video player UI object

    pos Vector2
    size Vector2
    src string

    Video file path or URL

    autoplay boolean optional, default false

    Start playing immediately?

    loop boolean optional, default false

    Loop the video?

    volume number optional, default 1

    Volume percent scaled by global volume (0-1)

    // Create a video player UI object
const video = new UIVideo(vec2(400, 300), vec2(320, 240), 'video.mp4', true);
video.play();
