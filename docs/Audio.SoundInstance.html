    Sound Instance - Wraps an AudioBufferSourceNode for individual sound control Represents a single playing instance of a sound with pause/resume capabilities

    Constructor

    new SoundInstance(sound, volume, rate, pan, loop, paused)engineAudio.js:495

    Create a sound instance

    sound Sound

    The sound object

    volume number optional, default 1

    How much to scale volume by

    rate number optional, default 1

    The playback rate to use

    pan number optional, default 0

    How much to apply stereo panning

    loop boolean optional, default false

    Should the sound loop?

    paused boolean optional, default false

    Should the sound start paused?

    // Play a sound and get an instance for control
const jumpSound = new Sound([.5,.5,220]);
const instance = jumpSound.play();

// Control the individual instance
instance.setVolume(.5);
instance.pause();
instance.resume();
instance.stop();

    setPan(pan)engineAudio.js:617

    Set the stereo pan of this sound instance, while it plays too

    • A looping sound can follow its source across the screen this way
    pan number

    -1 is left, 0 is center, 1 is right, clamped to that range

    setRate(rate)engineAudio.js:629

    Set the playback rate of this sound instance, its speed and pitch, while it plays

    • A looping sound can follow something smoothly this way, like an engine with the speed
    • A rate of 0 freezes the sound in place, and it carries on from there when the rate comes back
    rate number

    1 is normal, 2 is twice as fast and an octave up

    setVolume(volume, fadeTime)engineAudio.js:606

    Set the volume of this sound instance, with an optional fade to it

    • A fade ducks music under dialogue or cross fades two tracks without a click
    volume number
    fadeTime number optional, default 0

    Seconds to fade to the new volume over
