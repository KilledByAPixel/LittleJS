    TileCollisionLayer

    Tile Collision Layer - a tile layer with collision

    • adds collision data and functions to TileLayer
    • there can be multiple tile collision layers
    • its pos must be whole numbers, so its cells line up with the world grid objects land on

    Extends TileLayer

    World space size

    tileInfo TileInfo optional

    Tile info for layer, tile() by default, none when no image is loaded

    renderOrder number optional, default 0

    Objects are sorted by renderOrder

    useWebGL boolean optional, default true
